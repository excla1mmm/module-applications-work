# Запросы к сессии на Mac

Облачная сессия не имеет доступа к Jira, локальному checkout Core, Docker на arm64 (Apple Silicon) и аккаунту владельца.
Это делает сессия Claude Code на Mac. Обмен — через этот каталог в ветке `main`.

## Как попросить

1. Создай `requests/NNN-короткое-имя.md` (NNN — следующий номер, 001, 002…) по шаблону ниже.
2. Закоммить и запушь **в `main`** (только файлы в `requests/`; остальная работа — в своей ветке).
3. Скажи пользователю: «есть запрос NNN». Он передаст сессии на Mac.
4. Ответ появится в `requests/NNN-короткое-имя.answer.md` (+ файлы в `requests/NNN/`, если нужны). `git pull`.

```markdown
# NNN: заголовок
Тип: jira-read | jira-write | mac-run | core-lookup | other
Ветка/коммит: <если надо что-то прогнать из твоей ветки>
## Что нужно
Точная команда / текст комментария / вопрос.
## Зачем
1–2 строки.
## Ожидаемый результат
Что вернуть (вывод команды, файл, подтверждение).
```

## Типы

- **jira-read** — описание/комментарии/связи задачи (свежие копии LIC-* уже в `context/jira/`).
- **jira-write** — комментарий / start / done / новая задача. Приложи готовый markdown-текст. Mac-сессия публикует
  через jira-скилл; `done` и создание задач — только после подтверждения пользователя.
- **mac-run** — прогнать что-то на Mac (arm64 Docker, `tools/check`, pytest). Укажи ветку и команду.
- **core-lookup** — найти/прочитать что-то в локальном `mikopbx/Core` (develop), например API установки модулей.

Репозиторий публичный: никаких секретов и внутренних данных MIKO в запросах и ответах.
